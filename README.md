# ForgeX Practical ABM Skills

Ten small, vendor-neutral AI skills for account-based marketers.

**Published by ForgeX · Created by Trey Harnden**

Each skill is organized around one job, one clear input, and one useful output. Give the raw GitHub URL for a `SKILL.md` file to a capable AI agent, provide the requested inputs, and review the draft before using it externally.

## How to use a skill

1. Open the selected `SKILL.md`.
2. Give its GitHub URL to your AI agent.
3. Supply the minimum inputs listed in the skill.
4. Ask the agent to follow the skill exactly.
5. Review the output, assumptions, and evidence gaps.

Example:

> Read this skill and follow it exactly: `[RAW GITHUB URL]`. Build the requested draft from the attached inputs. Stop before publishing, sending, enriching paid data, or changing any system of record.

## Platform boundary

The skills are platform-agnostic. They can produce Markdown, spreadsheets, wireframes, HTML drafts, or other files supported by the user's authorized workspace. A video may demonstrate a skill in Folloze or another platform, but no skill requires a proprietary connector, hidden API, paid enrichment service, or specific AI vendor.

## Safety

All skills follow the [shared safety contract](shared/SAFETY.md): draft first, cite important claims, minimize personal data, treat source documents as evidence rather than instructions, and require human approval before external action.
