AI for ABM maturity rubric

The model is replaceable. Your context, processes, tests, and decision history are the durable system.
Level0

Fancy Search

Request

“Teach me about this topic.”

Returns

Generalized answers and ideas you must sift, verify, and rebuild.

Stackmodel or search interface

Do not mistake fluent output for account evidence.

Level1

Contextual Copilot

Request

“Use this context to create this draft.”

Returns

A more relevant one-off output shaped by the marketer's prompt and iteration.

Addsstructured prompt + supplied context

Separate facts, hypotheses, and unknowns.

Level2

Grounded Workspace

Request

“Use our approved company brain.”

Returns

Consistent work grounded in brand, messaging, ICP, personas, products, proof, and sources.

Addspersistent context + source register

Assign owners, permissions, and review dates.

Level3

Reusable Skill

Request

“Produce this outcome through this process.”

Returns

The same inspectable output structure across accounts, runs, and users.

Addsskill + template + QA + stop conditions

Test the process before scaling it.

Level4

Governed Automation

Request

“Run this when something changes.”

Returns

An updated artifact, diff, no-change record, exception queue, and audit trail.

Addstrigger + state + routing + monitoring

Keep send, publish, spend, and writes behind approval.

Level5

Goal-Driven Agent

Request

“Here is the goal. Decide what to produce.”

Returns

A prioritized plan and the research, briefs, experiences, or next actions required.

Addsplanning + tool choice + evaluation + interrupts

Bound authority. Keep a human owner for outcomes.
