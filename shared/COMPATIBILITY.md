# Agent compatibility

The skills use Markdown and ordinary files. They are designed for capable AI agents that can read supplied materials, optionally research the public web, and create draft documents or files.

No skill requires a particular model, custom API, MCP server, paid data provider, CRM, or publishing platform.

If browsing is unavailable, use supplied sources only and state the coverage limitation. If file creation is unavailable, return structured Markdown. If a requested platform is unavailable, stop at a platform-neutral brief, wireframe, or code draft.
